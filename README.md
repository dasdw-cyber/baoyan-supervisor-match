# 按学校筛选保研导师 · Supervisor Match

从一所目标学校出发，找到值得关注的导师、相关论文和具体联系依据。

[查看完整规则](SKILL.md) · [查看标准流程](保研导师筛选标准流程.md)

## 这是什么

确定了想申请的学校，打开教师目录，面对几十位老师和一长串研究方向，仍不知道该从谁开始了解。

研究方向看起来相关，具体做的问题却可能相差很远；找到一篇论文，也未必知道它和自己的经历有什么联系。

这个 Skill 根据你的意向方向或已有项目材料，查找导师、核实资料、精选论文，把选择依据整理成一份可以比较和继续使用的报告。

> 每个推荐，都说清老师研究什么、与你相关在哪里、接下来值得读什么。

## 使用前后

| 你目前掌握的信息 | Skill 帮你进一步理清 |
| --- | --- |
| 一所想申请的学校 | 相关院系、候选导师及实际检索范围 |
| 一个宽泛的研究方向 | 导师具体研究的问题、对象和方法 |
| 一段已有项目经历 | 可衔接的训练、研究差异与准备方向 |
| 一串论文题目 | 精选论文、选文理由和建议阅读重点 |
| 分散的主页与招生信息 | 带来源、年份和未知项的比较报告 |

已经明确想转向新方向时，以你的意向决定检索重点，再分析已有经历能够支持哪些环节。

## 快速开始

下载本仓库，在支持 Skill 的 AI 助手中加载。使用环境需具备联网检索能力；读取本地材料或保存论文时，需要相应的文件能力。

支持按名称调用时，可以这样开始：

```text
请使用 $baoyan-supervisor-match，帮我筛选〔学校全称〕的保研导师。

我希望研究〔意向方向〕，完整项目整理在〔文件位置〕。
请读取材料，查找相关导师和论文，
形成一份包含比较、研究依据和阅读建议的完整报告。
```

方向还没确定时，也可以这样开始：

```text
我想了解〔学校全称〕的导师，目前还没确定具体方向。

我的项目材料在〔文件位置〕。
请先提取已有训练，说明可以衔接哪些研究方向，
再查找导师与相关论文。
```

也可以让具备文件读取能力的 AI 先读取 `SKILL.md`，按标准流程开始。

## 会得到什么

默认交付一份完整的导师筛选报告，包含：

| 部分 | 主要内容 |
| --- | --- |
| 筛选依据与范围 | 学校、查阅院系、核查日期、个人方向与项目基础 |
| 导师比较总览 | 主要研究问题、具体连接、需补基础及招生信息 |
| 逐位导师分析 | 研究内容、关注理由、差异与支持来源 |
| 相关论文及解读 | 通常每位精选 1—2 篇，说明内容、联系和阅读重点 |
| 选择建议 | 有依据的关注顺序、优先阅读材料及待了解问题 |

默认保存为 Markdown，也可按指定格式交付。能够获取的公开论文 PDF 可作为配套阅读材料保存。

## 筛选怎样进行

1. **你确定学校。** 已给出学校时直接开展，相关院系由助手查找。
2. **读取方向和材料。** 提取真实经历与训练，区分已有基础和未来意愿。
3. **查找并比较导师。** 核实身份、现任单位及研究内容，解释具体联系。
4. **精选相关论文。** 核实论文归属，按实际读到的内容分析。
5. **完成一份报告。** 汇总比较、论文、选择建议与后续联系依据。

已有完整项目整理时直接复用；需要补充个人信息时，每轮默认只问一个关键问题。

## 核心特点

- **研究联系具体**：围绕问题、方法和实际训练分析匹配。
- **推荐附有论文依据**：选文随你的方向与经历调整。
- **跨方向也能分析**：说明可迁移的训练，以及需要补足的基础。
- **招生信息分别核实**：区分招生资格、招生类型与当年名额。
- **来源和阅读范围清楚**：记录实际核查时间、获取内容和未知项。

论文解读可以帮助你选择阅读入口；学生本人是否读过、理解了什么，另行记录。

## 与其他 Skill 衔接

**个人项目整理 → 按学校筛选导师 → 针对选定导师撰写自荐信**

上游的完整项目整理可直接作为输入。选定导师后，自荐信 Skill 可以承接本报告中的导师资料、已选论文、个人贡献与联系理由。

本 Skill 也可以独立使用：有目标学校和明确兴趣，就可以开始。
