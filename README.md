# 按学校筛选保研导师 · baoyan-supervisor-match

先由你确定学校，再结合你的意向研究方向或个人项目经历，查找合适的导师和相关论文，形成一份可供比较、阅读和后续自荐信使用的完整报告。

AI 负责查资料、解释研究内容和分析匹配依据。你不必先知道有哪些导师，也不必自己回答“我和哪位老师匹配”。

## 怎么使用

这是供 AI 助手读取的 Skill。使用环境需要能读取 Markdown 文件，并具备联网检索能力，以核实导师、论文与当前招生信息；读取本地材料或保存论文时还需要相应的文件能力。

下载 [技能压缩包](baoyan-supervisor-match.zip) 并解压，或通过 GitHub 的 Code → Download ZIP 下载本仓库。保留 `SKILL.md`、`保研导师筛选标准流程.md` 和 `agents/` 的目录关系，在支持 Skill 的工具中加载该目录。也可以让能读取本地文件的 AI 助手直接读取 `SKILL.md` 后开始。

支持按名称调用的环境中，可以这样开始：

```text
请使用 $baoyan-supervisor-match，帮我筛选保研导师。
先问我想申请哪所学校，再结合我的研究方向或项目材料查找导师及相关论文。
```

已经明确学校和方向时，可以直接提供：

```text
请先读取这个目录里的 SKILL.md。
我想申请〔学校全称〕，希望研究〔意向方向〕。
我的完整项目整理在〔文件位置〕，请直接读取，
筛选导师及相关论文，并形成一份完整报告。
```

还没有明确方向时也可以开始：

```text
我想了解〔学校全称〕的导师，但还没想好具体方向。
这是我已经整理好的项目经历，请先提取已有训练，
帮我了解有哪些可以衔接的研究方向，再查找导师和论文。
```

## 筛选过程

1. **先确定学校。** 学校由使用者选择；已经给出时直接使用，简称有歧义时再澄清。
2. **读取方向与材料。** 有明确意向就围绕意向筛选；方向未定时，从项目问题、方法、本人工作和已有训练中提取候选方向。过去做过什么与未来想做什么分别记录。
3. **查找导师并说明联系。** 核实身份、现任单位与研究内容，区分直接相关、方法可迁移和初步兴趣，说明差异与需要补足的基础。
4. **精选相关论文。** 通常为每位正式推荐导师选择 1—2 篇，与使用者的方向或项目有具体联系，并核实作者归属。
5. **交付一份完整报告。** 初筛与论文核实在制作过程中逐步完成，最终统一呈现。

已整理清楚的项目直接复用；需要补充信息时，每轮默认只问一个关键问题。没有完整项目整理，也可以从已有材料、粗略经历或明确兴趣开始。

## 报告包含什么

| 部分 | 内容 |
| --- | --- |
| 筛选依据与范围 | 指定学校、实际查阅院系、核查日期、意向方向及项目基础 |
| 导师比较总览 | 主要研究问题、与学生的具体连接、匹配性质、需补足的基础及招生信息 |
| 逐位导师分析 | 老师在研究什么、为什么值得关注、研究差异与相关证据 |
| 相关论文及解读 | 准确书目信息、来源链接、问题与方法、选文理由、阅读重点及实际阅读范围 |
| 选择建议 | 有依据的关注顺序、优先阅读的论文，以及需要进一步了解的问题 |

论文选择随学生方向和经历调整。每篇论文都应说明与学生的具体联系，解读以实际获取的内容为准；只读到摘要时明确标注。能获取的公开 PDF 可作为报告的配套阅读材料保存。

导师的招生资格、招生专业或类型与当年名额分别核实，未知信息明确记录。论文依据不足的导师单列为待核实候选，推荐理由用具体内容解释。

默认保存一份 Markdown 报告，也可按使用者指定的格式交付。

## 与其他步骤衔接

整体流程为：**个人项目整理 → 按学校筛选导师 → 针对选定导师撰写自荐信。**

已有完整项目整理时直接作为输入。需要先梳理经历，可以使用 [个人项目梳理 Skill](https://github.com/dasdw-cyber/project-experience-coach)。

后续自荐信可以直接读取本报告中的导师信息、选定论文、相关个人贡献和联系理由，再结合学生的实际阅读理解写作。AI 的论文解读与学生本人读过、复现过的经历分别记录。
